# Dice Hall mobile test builds

This public build configuration downloads the already-public Dice Hall game, verifies its hash, and compiles an unsigned arm64 iPhone IPA for uploading to Signulous. It contains no private repository files or signing keys.

The IPA requires signing before installation. It is a personal-device test build, not an App Store submission. Android test APKs are built separately and signature-verified before publication.

Play the game at https://farkle-dice-hall-test.darichughes.chatgpt.site/.
